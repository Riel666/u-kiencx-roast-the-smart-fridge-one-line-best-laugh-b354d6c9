The entry is one line, at most 160 characters, roasting the smart fridge:
a fridge that logs every midnight snack and tattles to your phone, yet
still needs a firmware update just to make ice.

`main.py` (Python 3, standard library only, no network) writes one line —
a roast of a smart fridge — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
